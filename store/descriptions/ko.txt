어떤 웹 동영상이든 내 언어 자막으로 보세요.

Subtitle Overlay는 어떤 웹사이트의 동영상 플레이어 위에든 자막을 표시하고, 전체 화면에서도 동영상과 정확히 동기화된 상태를 유지해요. 일시정지, 탐색, 재생 속도 변경도 그대로 잘 작동해요. 사이트에 이미 있는 자막을 내 언어로 번역해 쓰거나, 갖고 있는 .srt 또는 .vtt 파일을 불러올 수 있어요.

★ 주요 기능
★ 어떤 사이트, 어떤 동영상이든: 플레이어 위에 자막 표시, 창 모드와 전체 화면 모두 항상 동기화
★ 클릭 한 번으로 31개 언어로 번역하거나, 사이트 플레이어에서 자막을 켜는 즉시 완전히 자동으로 번역
★ 새 기능: AI로 번역을 자연스럽게. 내 컴퓨터에서 무료로(Gemma), 또는 내 Gemini, Claude, OpenAI 키로
★ 새 기능: 사이트에 이미 내 언어 자막이 있으면 그 자막을 바로 쓰고, 없을 때만 번역해요
★ 두 언어를 동시에: 하나는 위에, 하나는 아래에. 함께 보거나 언어를 배울 때 딱 좋아요
★ YouTube를 포함해 페이지가 불러오는 자막을 찾아 주니, 파일이 필요한 경우는 거의 없어요
★ 나만의 스타일: 1,800개 이상의 Google Fonts, 외곽선, 그림자, 배경 상자, 크기와 위치
★ 무료 오픈 소스: 광고 없음, 계정 없음, 추적 없음, 모든 코드가 공개되어 있어요

【31개 언어로 번역】
• 불러온 자막을 확장 프로그램 안에서 클릭 한 번으로 Google 번역
• 선택 사항: "개선"을 클릭하면 AI(내 컴퓨터의 Gemma, 또는 Gemini, Claude, OpenAI)가 Google의 빠른 번역을 자연스럽게 다시 써요(자세한 내용은 아래). 동영상 위에 마우스를 올리면 진행 상황을 볼 수 있어요
• 언어는 한 번만 고르면 모든 "번역" 버튼에 그대로 적용돼요
• 자동 모드: 사이트 플레이어에서 자막을 켜면 이미 번역된 자막이 동영상 위에 나타나고, 팝업 대신 짧은 "…(으)로 번역됨" 알림만 표시돼요. 새로 설치하면 켜진 상태로 시작하며 브라우저 언어로 번역해요
• 사이트에 내 언어 자막이 있으면(YouTube와 스트리밍 서비스) 그 자막이 먼저 나오고, Google이나 AI는 없을 때만 번역해요
• 저희 자막이 켜져 있는 동안 사이트 자체 자막은 숨겨지고, 저희 자막을 끄면 바로 다시 나타나요
• 언제든 원문으로 돌아가거나, 번역을 .srt 파일로 저장할 수 있어요
• 지원 언어: 베트남어, 체코어, 영어, 슬로바키아어, 독일어, 프랑스어, 스페인어, 이탈리아어, 포르투갈어, 폴란드어, 헝가리어, 우크라이나어, 네덜란드어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어, 그리스어, 튀르키예어, 루마니아어, 크로아티아어, 중국어(간체 및 번체), 일본어, 한국어, 태국어, 인도네시아어, 말레이어, 필리핀어, 힌디어, 아랍어

【자연스러운 번역(선택 사항)】
Google 번역은 빠르지만 한 줄씩, 단어 단위로 번역해요. "개선"을 클릭하면 AI 모델이 장면 전체를 고려해, 지금 보고 있는 지점부터 자막을 다시 써요.
• 무료: Google의 오픈 모델 Gemma가 Ollama 또는 LM Studio를 통해 내 컴퓨터에서 실행되므로 AI 처리 과정이 내 컴퓨터 밖으로 나가지 않아요. 꽤 성능 좋은 컴퓨터와 약 8 GB의 디스크 공간이 필요해요.
• 확장 프로그램 창이 단계별로 안내해요: ollama.com에서 Ollama를 설치하고 클릭 한 번으로 Gemma를 내려받으세요(RAM 16GB 이상 필요). 자세한 내용과 현재 추천 모델(영어 페이지): cleedek.com/subtitle-overlay/ai
• 또는 내 API 키 사용: Gemini(무료 등급 있음), Claude 또는 OpenAI(유료).
• 시작하기 전에 파일 전체를 훑어보며 누가 누구인지 정리해 두기 때문에, 성별, 호칭, 이름이 첫 줄부터 마지막 줄까지 일관되게 유지돼요.
• 절대 저절로 시작하지 않아요. 내가 클릭하지 않으면 아무것도 실행되지 않고 비용도 들지 않아요.

【두 언어를 동시에】
• 원하는 언어로 두 번째 자막을 켜세요. 위에는 나를 위한 영어, 아래에는 파트너를 위한 베트남어
• 원문을 번역 옆에 그대로 둘 수도 있어 언어 공부에 아주 좋아요
• 자막마다 가장자리와의 거리를 따로 정할 수 있어요
• 동영상 위의 작은 패널에서 국기 옆 스위치로 각 언어를 켜고 끌 수 있고, 나머지 하나는 원래 자리로 이동해요

【사이트가 불러오는 자막 찾기】
• 페이지가 자막(VTT 파일이나 스트리밍 자막 재생목록)을 불러오면 작은 카드가 나타나 자막을 알려 줘요. 페이지가 제공하면 영화나 에피소드 제목도 함께 보여 줘요
• YouTube: CC를 켜면 내 언어로 자막을 읽을 수 있어요. YouTube의 CC 버튼으로 켜고 끌 수 있고, 플레이어 컨트롤이 나타나면 자막이 위로 올라가요
• 표시, 번역, .srt로 저장을 클릭 한 번으로
• 한 페이지에 동영상이 여러 개 있나요? 자막이 어느 동영상의 것인지 고를 수 있어요

【번역 대기열과 저장된 자막】
• 여러 개의 .srt 또는 .vtt 파일을 넣거나, 사이트가 불러온 자막에서 "대기열에 추가"를 클릭하세요. 다른 일을 하는 동안 하나씩 차례로 번역되며, 대기열 탭은 백그라운드에 두어도 괜찮아요
• Google, Gemini, Claude, OpenAI 또는 로컬 모델과 함께 작동해요
• 개선된 자막은 원하는 기간 동안 확장 프로그램에 보관되고, 그 동영상으로 돌아오면 다시 나타나요, 같은 자막이 있는 다른 페이지에서도 AI에 다시 요청하지 않고 바로 사용됩니다
• "재생"은 자막과 함께 동영상을 열고, "다음에 표시…"는 다른 탭에 이미 열려 있는 동영상 위에 자막을 띄우고, ".srt 다운로드"는 .srt 파일을 저장해요

【내 마음대로 스타일링】
• 1,800개 이상의 Google Fonts 중 내 언어의 글자를 지원하는 글꼴만 골라서 보여 줘요(č ř ž, ư ế ộ, 키릴 문자, 그리스 문자, 일본어 등)
• 크기, 굵기, 색상, 외곽선(투명도 별도 조절), 그림자, 배경 상자(뒤쪽 흐림 효과 선택 가능), 줄 너비
• 동영상 아래, 가운데 또는 위에 표시
• 프리셋("깔끔하게", "상자형", "고대비")과 직접 저장한 스타일
• 텍스트가 플레이어 크기에 맞춰 조절되며, 확장 프로그램 창에서 실시간 미리 보기를 제공해요
• 탭 세 개로 깔끔하게 정리된 창: "자막", "스타일", "동작". 어두운 테마와 밝은 테마 지원(시스템 설정 따르기도 가능)
• [음악] 같은 소리 표시와 >> 화자 표시를 숨겨요(스위치 하나로 다시 표시)

【싱크 맞추기】
• 확장 프로그램 창이나 키보드로 자막을 0.1초 또는 1초 단위로 앞당기거나 늦출 수 있어요
• 조정한 값은 페이지별로 기억돼요

【언어 학습에 딱】
• 대사를 놓쳤나요? Alt + R을 누르면 그 줄을 처음부터 다시 재생해요
• 아무 줄이나 클릭하면 복사되어 사전이나 메모에 바로 쓸 수 있어요

【내 파일 사용】
• .srt 또는 .vtt 파일을 선택하거나 동영상 위로 바로 끌어다 놓으세요
• 글자가 깨지나요? 텍스트 인코딩 자동 감지(일본어, 중국어, 한국어 파일도 지원)와 수동 지정 기능이 있어요
• 페이지를 새로고침하거나 나중에 다시 와도 자막이 그대로 돌아와요

【자막이 유지되는 전체 화면】
• Alt + F 또는 동영상 상단의 버튼으로 전체 화면에 들어가고, F 키나 "전체 화면 종료" 버튼으로 나올 수 있어요
• 사이트 메뉴나 알림이 자막을 가리면 자막이 알아서 비켜 줘요

【사이트별 설정】
• 스위치 하나로 어떤 사이트에서든 끌 수 있고, 꺼 둔 사이트 목록도 클릭 한 번이면 볼 수 있어요

【키보드 단축키】
Alt + [ / ] 싱크 · Alt + Shift + [ / ] 1초 단위 싱크 · Alt + 0 싱크 초기화 · Alt + R 그 줄 반복 · Alt + S 표시/숨기기 · Alt + 1 / Alt + 2 한 언어만 표시/숨기기 · Alt + ↑ / ↓ 이동 · Alt + F 자막과 함께 전체 화면
모든 단축키는 "동작" 탭에서 바꾸거나 끌 수 있어요.

【31개 언어 인터페이스】
영어, 체코어, 슬로바키아어, 독일어, 프랑스어, 스페인어, 베트남어, 중국어(간체), 중국어(번체), 이탈리아어, 포르투갈어, 폴란드어, 우크라이나어, 헝가리어, 네덜란드어, 스웨덴어, 덴마크어, 노르웨이어, 핀란드어, 그리스어, 튀르키예어, 루마니아어, 크로아티아어, 일본어, 한국어, 태국어, 인도네시아어, 말레이어, 필리핀어, 힌디어, 아랍어(오른쪽에서 왼쪽). 브라우저 언어를 따르며, 확장 프로그램 창 하단에서 직접 고를 수도 있어요.

【파고드는 분들을 위해】
DevTools의 "Subtitles" 탭에서 페이지가 불러온 모든 자막 파일을 확인하고 .vtt 또는 .srt로 저장할 수 있어요.

【개인정보 보호】
계정 없음, 분석 도구 없음, 추적 없음. 자막 텍스트는 자막을 번역할 때(내가 클릭하거나 자동 모드일 때)만 Google 번역으로 전송되고, "개선"을 클릭할 때만 Gemini, Claude, OpenAI 또는 로컬 모델로 전송돼요. 기억되거나 저장된 자막은 내 브라우저에 남아 있어요. 확장 프로그램 창의 "메시지 보내기"로 연락하면 메시지는 이메일로 저에게 전달돼요. 문제 신고는 보내기를 누를 때만 전송되며, 페이지 주소가 아닌 사이트 이름만 담깁니다. 자세한 내용은 개인정보처리방침을 확인하세요.

【문제나 아이디어가 있나요?】
확장 프로그램 창 하단의 "문제나 아이디어가 있나요?"를 클릭해 메시지를 보내 주세요. 모든 메시지를 직접 읽어요. 사이트에서 자막이 보이지 않나요? 동영상 위의 "도움말" 라벨이 안내해 주고, "문제 신고"를 누르면 사이트 이름이 저에게 전송되어 고칠 수 있습니다.

【오픈 소스】
확장 프로그램 전체가 오픈 소스(GPL-3.0)라서 누구나 정확히 무엇을 하는지 확인할 수 있어요: github.com/Cleedek/subtitle-overlay. 마음에 드셨다면 GitHub에서 별표를 눌러 주세요. 다른 사람들이 찾는 데 도움이 돼요.

【제작자 후원하기】
Subtitle Overlay는 무료이고, 모든 기능은 앞으로도 계속 무료예요. 저녁 시간이 조금 더 즐거워졌다면, 확장 프로그램 창의 "제작자 후원하기" 페이지에서 Ko-fi 등 여러 방법으로 후원할 수 있어요. 동영상을 많이 번역하고 나면 동영상 위의 작은 카드로도 한 번 여쭤봐요(최대 동영상 3개까지, 한 번 클릭하면 다시 나타나지 않아요). 완전히 선택 사항이에요. 고맙습니다!

베트남에서 Cleedek이 💜을 담아 만들었어요.

Subtitle Overlay는 독립 프로젝트예요. 함께 작동하는 웹사이트나 스트리밍 서비스 어디와도 제휴, 보증, 후원 관계가 없어요. 그곳에서 작동하는 건 저희가 직접 한 작업이에요. 해당 사이트에서 테스트했고, 일부 사이트는 플레이어에 맞게 조정했어요. 각 서비스의 이름과 로고는 해당 소유자의 것이에요.
