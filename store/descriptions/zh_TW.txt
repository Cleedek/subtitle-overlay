用你的語言，為任何網路影片配上字幕。

Subtitle Overlay 會把字幕顯示在任何網站的影片播放器上，全螢幕時也一樣，並始終與影片保持同步：暫停、跳轉、調整播放速度都沒問題。你可以使用網站原有的字幕並翻譯成你的語言，也可以使用你自己的 .srt 或 .vtt 檔案。

★ 亮點
★ 任何網站、任何影片：字幕顯示在播放器上，視窗或全螢幕皆可，始終同步
★ 一鍵翻譯成 31 種語言；也可以全自動：只要在網站的播放器中開啟字幕，就會自動翻譯
★ 新功能：用 AI 讓譯文讀起來更自然，可在你自己的電腦上免費執行（Gemma），或使用你自己的 Gemini、Claude 或 OpenAI 金鑰
★ 新功能：可以為一整季影集排好翻譯佇列，改善後的字幕會儲存起來，下次直接使用
★ 同時顯示兩種語言：一種在上方，一種在下方，適合一起觀看或學習語言
★ 自動找到網頁載入的字幕（包括 YouTube），所以你幾乎不需要另外找字幕檔
★ 你的風格：1,800+ 款 Google Fonts 字型，外框、陰影、底框、大小和位置都可調整
★ 免費且開放原始碼：沒有廣告，不需帳號，沒有追蹤，每一行程式碼都公開

【翻譯成 31 種語言】
• 一鍵用 Google 翻譯翻譯已載入的字幕，直接在擴充功能中完成
• 可選：點選"改善"，AI（你電腦上的 Gemma，或 Gemini、Claude、OpenAI）會改寫 Google 的快速譯文，讓它讀起來更自然（詳見下文）。把滑鼠移到影片上就能看到進度
• 語言只要選一次，之後每個"翻譯"按鈕都會預設使用它
• 自動模式：在網站的播放器中開啟字幕，字幕就會直接以譯文出現在影片上，只顯示一則簡短的"已翻譯成……"提示，不會跳出視窗打擾你。新安裝時預設開啟，並翻譯成你的瀏覽器語言
• 網站原有的字幕會被隱藏，你不會同時看到兩套字幕
• 隨時可以切回原文，或把譯文儲存為 .srt 檔案
• 支援語言：越南語、捷克語、英語、斯洛伐克語、德語、法語、西班牙語、義大利語、葡萄牙語、波蘭語、匈牙利語、烏克蘭語、荷蘭語、瑞典語、丹麥語、挪威語、芬蘭語、希臘語、土耳其語、羅馬尼亞語、克羅埃西亞語、中文（簡體和繁體）、日語、韓語、泰語、印尼語、馬來語、菲律賓語、印地語、阿拉伯語

【讓譯文更自然（可選）】
Google 翻譯很快，但它是逐行、逐字翻譯。點選"改善"，AI 模型會考量整個場景來改寫字幕，從你正在觀看的位置開始。
• 免費：Gemma 是 Google 的開放模型，可透過 Ollama 或 LM Studio 在你自己的電腦上執行，所以 AI 這個步驟都留在你的電腦上。你需要一台效能較強的電腦，以及大約 8 GB 的磁碟空間。
• 3 步驟設定：從 ollama.com 安裝 Ollama，用一行指令下載 Gemma，然後在擴充功能視窗中選擇"本機"。指令和我們目前推薦的模型請見（英文頁面）：cleedek.com/subtitle-overlay/ai
• 也可以使用你自己的 API 金鑰：Gemini（有免費額度）、Claude 或 OpenAI（付費）。
• 開始之前，它會先瀏覽整個字幕檔，記下誰是誰，讓性別、稱呼和人名從第一句到最後一句都保持一致。
• 它絕不會自行開始：沒有你的點選，什麼都不會執行，也不會產生任何費用。

【同時顯示兩種語言】
• 開啟任意語言的第二字幕：上方是給你看的英語，下方是給另一半看的越南語
• 或者把原文和譯文並列顯示，非常適合學習
• 每套字幕都有各自與邊緣的距離
• 影片上的小面板可在每種語言的國旗旁開啟或關閉該語言；另一種語言會移到平常的位置

【自動找到網站載入的字幕】
• 當網頁載入字幕（VTT 檔案或串流字幕播放清單）時，會出現一張小卡片提供這些字幕；如果網頁提供了電影或單集標題，也會一併顯示
• YouTube：開啟 CC，就能用你的語言閱讀字幕；YouTube 本身的 CC 按鈕可開關它們，播放器控制列出現時字幕會自動上移
• 一鍵顯示、翻譯或儲存為 .srt
• 同一個頁面上有多部影片？選擇字幕屬於哪一部

【翻譯佇列和已儲存的字幕】
• 拖入多個 .srt 或 .vtt 檔案，或在網站載入的字幕上點選"加入佇列"。它們會一個接一個翻譯，你可以同時做別的事；佇列分頁可以留在背景
• 支援 Google、Gemini、Claude、OpenAI 或你的本機模型
• 改善後的字幕會依你選擇的時間保存在擴充功能中，你回到該影片時會自動恢復
• "播放"會開啟影片並顯示其字幕；"下載"會儲存 .srt

【依你的方式設定樣式】
• 1,800+ 款 Google Fonts 字型，只顯示包含你語言字母的字型（č ř ž、ư ế ộ、西里爾字母、希臘字母、日文等）
• 大小、粗細、顏色、外框（可單獨調整透明度）、陰影、底框（可選背景模糊）以及行寬
• 顯示在影片底部、中間或頂部
• 預設組合（"簡潔"、"加底框"、"高對比"），以及你自己儲存的外觀
• 文字隨播放器縮放，擴充功能視窗中可即時預覽
• 簡潔的擴充功能視窗分為三個分頁："字幕"、"樣式"和"行為"，可選深色或淺色外觀（或跟隨系統）
• 隱藏 [Music] 之類的聲音標註和 >> 說話者標記（一個開關即可恢復）

【調整時間軸】
• 以 0.1 秒或 1 秒為單位讓字幕提前或延後，可在擴充功能視窗中或用鍵盤操作
• 調整會隨頁面一起記住

【為學習而設計】
• 漏聽了一句？Alt + R 從頭重播這一句
• 點選任意一行即可複製，方便查字典或做筆記

【你自己的檔案】
• 選擇一個 .srt 或 .vtt 檔案，或直接拖到影片上
• 文字變成亂碼？自動偵測文字編碼（也支援日文、中文和韓文檔案），也可以手動指定
• 重新載入頁面或之後再回來時，你的字幕會自動恢復

【全螢幕也保留字幕】
• 按 Alt + F 或點選影片頂部的按鈕；按 F 或點選"結束全螢幕"按鈕即可退出
• 當網站選單或通知遮住字幕時，字幕會自動讓開

【依網站設定】
• 一個開關即可在任何網站上關閉它；已關閉網站的清單一鍵可見

【鍵盤快速鍵】
Alt + [ / ] 同步 · Alt + Shift + [ / ] 以 1 秒為單位同步 · Alt + 0 重設同步 · Alt + R 重播這一句 · Alt + S 顯示或隱藏 · Alt + 1 / Alt + 2 只顯示或隱藏其中一種語言 · Alt + ↑ / ↓ 移動 · Alt + F 帶字幕全螢幕
每個快速鍵都可以在"行為"分頁中變更或關閉。

【介面支援 31 種語言】
英語、捷克語、斯洛伐克語、德語、法語、西班牙語、越南語、簡體中文、繁體中文、義大利語、葡萄牙語、波蘭語、烏克蘭語、匈牙利語、荷蘭語、瑞典語、丹麥語、挪威語、芬蘭語、希臘語、土耳其語、羅馬尼亞語、克羅埃西亞語、日語、韓語、泰語、印尼語、馬來語、菲律賓語、印地語和阿拉伯語（由右至左）。介面會跟隨你的瀏覽器語言，也可以在擴充功能視窗底部自行選擇。

【給愛動手研究的你】
DevTools 中的"Subtitles"分頁會列出網頁載入的每個字幕檔，並可儲存為 .vtt 或 .srt。

【隱私】
沒有帳號，沒有統計分析，沒有追蹤。字幕文字只有在翻譯字幕時（你點選或自動模式）才會傳送給 Google 翻譯，只有在你點選"改善"時才會傳送給 Gemini、Claude、OpenAI 或你的本機模型。記住的和儲存的字幕都留在你的瀏覽器中。如果你透過擴充功能視窗中的"寫信給我"留言，你的訊息會以電子郵件寄給我。詳情請見隱私權政策。

【遇到問題或有想法？】
