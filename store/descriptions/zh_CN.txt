用你的语言给任何网页视频配上字幕。

Subtitle Overlay 会把字幕显示在任何网站的视频播放器上，全屏时也一样，并始终与视频保持同步：暂停、跳转、调整播放速度都没问题。你可以使用网站自带的字幕并翻译成你的语言，也可以使用你自己的 .srt 或 .vtt 文件。

★ 亮点
★ 任何网站、任何视频：字幕显示在播放器上，窗口或全屏都可以，始终同步
★ 一键翻译成 31 种语言；也可以全自动：只要在网站的播放器里打开字幕就会自动翻译
★ 新功能：用 AI 让译文读起来更自然，可在你自己的电脑上免费运行（Gemma），或使用你自己的 Gemini、Claude 或 OpenAI 密钥
★ 新功能：如果网站已有你语言的字幕，就直接使用它，只有没有时才翻译
★ 同时显示两种语言：一种在上方，一种在下方，适合一起观看或学习语言
★ 自动找到网页加载的字幕（包括 YouTube），所以你几乎不需要自己找字幕文件
★ 你的风格：1,800+ 款 Google Fonts 字体，描边、阴影、底框、大小和位置都可调
★ 免费且开源：没有广告，无需账号，没有跟踪，每一行代码都公开

【翻译成 31 种语言】
• 一键用 Google 翻译翻译已加载的字幕，直接在扩展里完成
• 可选：点击"改进"，AI（你电脑上的 Gemma，或 Gemini、Claude、OpenAI）会重写 Google 的快速译文，让它读起来更自然（详见下文）。把鼠标移到视频上就能看到进度
• 语言只需选一次，之后每个"翻译"按钮都会默认使用它
• 自动模式：在网站的播放器里打开字幕，它们就会以译文形式出现在视频上，只显示一条简短的"已翻译成……"提示，不会弹窗打扰。新安装时默认开启，并翻译成你的浏览器语言
• 如果网站有你语言的字幕（YouTube 和流媒体平台），会优先使用；只有没有时，Google 或 AI 才会翻译
• 我们的字幕开启时，网站自带的字幕会被隐藏；关闭我们的字幕后，它们会立即恢复
• 随时可以切回原文，或把译文保存为 .srt 文件
• 支持语言：越南语、捷克语、英语、斯洛伐克语、德语、法语、西班牙语、意大利语、葡萄牙语、波兰语、匈牙利语、乌克兰语、荷兰语、瑞典语、丹麦语、挪威语、芬兰语、希腊语、土耳其语、罗马尼亚语、克罗地亚语、中文（简体和繁体）、日语、韩语、泰语、印尼语、马来语、菲律宾语、印地语、阿拉伯语

【让译文更自然（可选）】
Google 翻译很快，但它是逐行、逐词地翻译。点击"改进"，AI 模型会结合整个场景重写字幕，从你正在观看的位置开始。
• 免费：Gemma 是 Google 的开放模型，可通过 Ollama 或 LM Studio 在你自己的电脑上运行，所以 AI 这一步都留在你的电脑上。你需要一台性能较强的电脑，以及大约 8 GB 的磁盘空间。
• 弹窗会一步步引导你：从 ollama.com 安装 Ollama，然后一键下载 Gemma（至少需要 16 GB 内存）。更多信息和我们目前推荐的模型见：cleedek.com/subtitle-overlay/ai
• 也可以使用你自己的 API 密钥：Gemini（有免费额度）、Claude 或 OpenAI（付费）。
• 开始之前，它会先浏览整个字幕文件，记下谁是谁，让性别、称呼和人名从第一句到最后一句都保持一致。
• 它从不自动开始：没有你的点击，什么都不会运行，也不会产生任何费用。

【同时显示两种语言】
• 打开任意语言的第二套字幕：上方是给你看的英语，下方是给你伴侣看的越南语
• 或者把原文和译文并排显示，非常适合学习
• 每套字幕都有各自与边缘的距离
• 视频上的小面板可在每种语言的国旗旁开启或关闭它；另一种语言会移到常规位置

【自动找到网站加载的字幕】
• 当网页加载字幕（VTT 文件或流媒体字幕播放列表）时，会出现一张小卡片提供这些字幕；如果网页提供了电影或剧集标题，也会一并显示
• YouTube：打开 CC，就能用你的语言阅读字幕；YouTube 自己的 CC 按钮可开关它们，播放器控件出现时字幕会自动上移
• 一键显示、翻译或保存为 .srt
• 一个页面上有多个视频？选择字幕属于哪一个

【翻译队列和已保存的字幕】
• 拖入多个 .srt 或 .vtt 文件，或在网站加载的字幕上点击"加入队列"。它们会一个接一个地翻译，你可以同时做别的事；队列标签页可以留在后台
• 支持 Google、Gemini、Claude、OpenAI 或你的本地模型
• 改进后的字幕会按你选择的时长保存在扩展中，你回到该视频时会自动恢复
• "播放"会打开视频并显示其字幕；"显示到…"会把字幕放到另一个标签页中已打开的视频上；"下载"会保存 .srt

【按你的方式设置样式】
• 1,800+ 款 Google Fonts 字体，只显示包含你语言字母的字体（č ř ž、ư ế ộ、西里尔字母、希腊字母、日文等）
• 大小、粗细、颜色、描边（可单独调透明度）、投影、底框（可选背景模糊）以及行宽
• 显示在视频底部、中间或顶部
• 预设（"简洁"、"带底框"、"高对比度"），以及你自己保存的外观
• 文字随播放器缩放，弹窗中可实时预览
• 简洁的弹窗分为三个标签页："字幕"、"样式"和"行为"，可选深色或浅色外观（或跟随系统）
• 隐藏 [Music] 之类的声音标注和 >> 说话人标记（一个开关即可恢复）

【调整时间轴】
• 以 0.1 秒或 1 秒为单位让字幕提前或延后，可在弹窗中或用键盘操作
• 调整会随页面一起记住

【为学习而设计】
• 漏听了一句？Alt + R 从头重播这一句
• 点击任意一行即可复制，方便查词典或记笔记

【你自己的文件】
• 选择一个 .srt 或 .vtt 文件，或直接拖到视频上
• 文字乱码？自动检测文本编码（也支持日文、中文和韩文文件），也可以手动指定
• 重新加载页面或之后再回来时，你的字幕会自动恢复

【全屏也保留字幕】
• 按 Alt + F 或点击视频顶部的按钮；按 F 或点击"退出全屏"按钮退出
• 当网站菜单或通知遮挡字幕时，字幕会自动让开

【按网站设置】
• 一个开关即可在任何网站上关闭它；已关闭网站的列表一键可见

【键盘快捷键】
Alt + [ / ] 同步 · Alt + Shift + [ / ] 按 1 秒同步 · Alt + 0 重置同步 · Alt + R 重播这一句 · Alt + S 显示或隐藏 · Alt + 1 / Alt + 2 只显示或隐藏其中一种语言 · Alt + ↑ / ↓ 移动 · Alt + F 带字幕全屏
每个快捷键都可以在"行为"标签页中更改或关闭。

英语、捷克语、斯洛伐克语、德语、法语、西班牙语、越南语、简体中文、繁体中文、意大利语、葡萄牙语、波兰语、乌克兰语、匈牙利语、荷兰语、瑞典语、丹麦语、挪威语、芬兰语、希腊语、土耳其语、罗马尼亚语、克罗地亚语、日语、韩语、泰语、印度尼西亚语、马来语、菲律宾语、印地语和阿拉伯语（从右到左）。界面会跟随你的浏览器语言，也可以在弹窗底部自行选择。

【给爱折腾的你】
DevTools 中的"Subtitles"标签页会列出网页加载的每个字幕文件，并可保存为 .vtt 或 .srt。

【隐私】
没有账号，没有统计分析，没有跟踪。字幕文本只有在翻译字幕时（你点击或自动模式）才会发送给 Google 翻译，只有在你点击"改进"时才会发送给 Gemini、Claude、OpenAI 或你的本地模型。记住的和保存的字幕都留在你的浏览器中。如果你通过弹窗里的"给我留言"写信给我，你的消息会通过电子邮件发给我。详情请见隐私政策。
